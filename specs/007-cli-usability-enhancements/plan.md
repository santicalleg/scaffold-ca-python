# Implementation Plan: CLI Usability Enhancements

**Branch**: `007-cli-usability-enhancements` | **Date**: 2026-03-30 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `/specs/007-cli-usability-enhancements/spec.md`

## Summary

Rename the primary scaffolding command from `generate-project` to `clean-architecture` (alias `ca` preserved); add rich types-table and Examples epilogs to `gep --help`, `gda --help`, and `gpipe --help`; make the root command and all subcommands show help and exit 0 when invoked with no arguments.

Technical approach: (1) rename Typer command registration in `generate_project.py`; (2) add `rich_markup_mode="rich"` to root `Typer()` and `epilog=` params on three commands; (3) replace `no_args_is_help=True` on root with `@app.callback(invoke_without_command=True)` and add `ctx: typer.Context` + optional-option guards to every subcommand. No new templates, no new data models, no new dependencies.
