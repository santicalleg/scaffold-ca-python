# Quickstart: Fix RestAPI Entry Point Test Templates

**Feature**: `012-fix-restapi-test-templates` | **Date**: 2026-04-10

---

## Problem Summary

When `gep --type restapi` generates a project, the generated tests fail immediately with:
- `ImportError: cannot import name 'create_app' from '…server'` — wrong import in `test_rest_controller.py.jinja2`
- `schemas.py` / `test_schemas.py` are missing — templates for them were never created
- The CLI's own test suite fails on 7–8 tests (missing templates + stale test references)

## Fix Summary (3 changes)

### 1 — Rewrite `test_rest_controller.py.jinja2`

**File**: `src/scaffold_ca_python/templates/entry_point/restapi/test_rest_controller.py.jinja2`

Replace the entire file (duplicate two-block content) with a single clean block:
- Import `create_app` from `{{ project.python_package }}.application.app` (not `server`)
- One `@pytest.fixture` that returns `TestClient(create_app())`
- Two tests: `test_health_returns_200`, `test_health_returns_online_status`

### 2 — Create three new templates

**Files to create**:

| File | Purpose |
|---|---|
| `schemas.py.jinja2` | Pydantic v2 `ExampleResponse` + optional swagger route stubs |
| `test_schemas.py.jinja2` | Imports + instantiates `ExampleResponse`, asserts `.status == "ok"` |
| `router.py.jinja2` | Supplemental standalone APIRouter for CLI template test coverage |

### 3 — Wire `schemas.py` + `test_schemas.py` into `_build_operations`

**File**: `src/scaffold_ca_python/commands/generate_entry_point.py`

In the `restapi` branch of `_build_operations`, add after `exception_handler.py`:
```python
_src("schemas.py.jinja2", "schemas.py"),
_test("test_schemas.py.jinja2", "test_schemas.py"),
```

### 4 — Remove two stale CLI template tests

**File**: `tests/templates/test_entry_point_templates.py`

Delete `test_restapi_main_has_fastapi_import` and `test_restapi_main_has_create_app` — 
these reference `entry_point/restapi/main.py.jinja2` which no longer exists (feature 011).
