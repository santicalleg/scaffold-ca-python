# Implementation Plan: Clean Architecture Scaffold Enhancements

**Branch**: `006-ca-scaffold-enhancements` | **Date**: 2026-03-27 | **Spec**: [spec.md](spec.md)

## Summary

Evolve the `scaffold ca` command and the `gep`/`gda` commands to produce production-ready project skeletons. Four concrete changes: (1) remove the unused `--package` flag, (2) add Docker and Python-version pinning files to the generated root and move ruff config inline into `pyproject.toml`, (3) scaffold a `dependency-injector` DI container under `application/config/` at project creation, (4) create `main.py` on project creation and overwrite it per entry-point type, and auto-append third-party package names to `[project.dependencies]` on driven-adapter and entry-point creation.

---

## Research (Phase 0)

### R-01: TOML write-back strategy

**Decision**: Use `tomli-w` for serialising the modified TOML document.  
**Rationale**: `tomllib` (stdlib, Python 3.11+) is read-only. `tomli-w` is the official write-counterpart, maintained by the same author, used by uv itself. It preserves key order. Alternative (`tomlkit`) was rejected because it preserves formatting (useful for human-edited files) but adds 10× more complexity and a heavier dep.  
**Integration**: Add `tomli-w>=1.0` to `[dependencies]` in `scaffold-ca-python`'s own `pyproject.toml`.  
**Write pattern**:
```python
import tomllib, tomli_w

with (project_root / "pyproject.toml").open("rb") as fh:
    data = tomllib.load(fh)

deps: list[str] = data.setdefault("project", {}).setdefault("dependencies", [])
for pkg in NEW_PACKAGES:
    if not any(dep.startswith(pkg.split(">=")[0].split("[")[0]) for dep in deps):
        deps.append(pkg)

with (project_root / "pyproject.toml").open("wb") as fh:
    tomli_w.dump(data, fh)
```

### R-02: Static dependency map

**Decision**: Define a module-level `dict` in each command module.  
**Rationale**: No runtime discovery needed. The set of packages per type is fixed and should be auditable from a single location.

```python
# generate_entry_point.py
_DEP_MAP: dict[str, list[str]] = {
    "restapi": ["fastapi>=0.100", "uvicorn[standard]>=0.20"],
    "agent":   ["a2a-sdk>=0.1"],
    "mcp":     ["mcp>=1.0"],
    "generic": [],
}

# generate_driven_adapter.py
_DEP_MAP: dict[str, list[str]] = {
    "rest-consumer": ["httpx>=0.27"],
    "secrets":       ["boto3>=1.34"],
    "generic":       [],
}
```

### R-03: `main.py` overwrite pattern

**Decision**: `generate_entry_point.py` renders `entry_point/<type>/entrypoint_main.py.jinja2` and writes it to `src/<pkg>/main.py` as a `CreateFile` operation — passing `overwrite=True` to `FileWriter` (new flag), or by pre-deleting then creating.  
**Rationale**: `FileWriter._commit` uses `os.replace` which already overwrites atomically. The only change needed is to skip the "path must not exist" guard for this single file. Simplest approach: add a boolean `overwrite: bool = False` to `GeneratedFile`; `FileWriter` skips the parent-dir guard when `overwrite=True`.  
**Warning**: `console.print("[yellow]⚠[/yellow] main.py will be replaced ...")` before writing.

### R-04: `ProjectContext.package` removal impact

**Files that construct `ProjectContext` directly and need `package` removed**:
- `src/scaffold_ca_python/commands/generate_project.py` — `_generate_project_impl`
- `src/scaffold_ca_python/models/context.py` — field definition
- `src/scaffold_ca_python/templates/project/pyproject_toml.jinja2` — `package = "{{ package }}"` in `[tool.scaffold-ca-python]`
- All `_load_project_context(root)` helper functions in `generate_model.py`, `generate_use_case.py`, `generate_driven_adapter.py`, `generate_entry_point.py`, `generate_helper.py`, `generate_pipeline.py`, `delete_module.py`, `validate_structure.py`, `update_project.py` (they read `section.get("package", ...)` and pass it to `ProjectContext`)
- All test files that pass `package=` to `ProjectContext`

### R-05: Ruff config consolidation

**Current state**: `pyproject_toml.jinja2` already includes a minimal `[tool.ruff]` block. `ruff_toml.jinja2` has a richer config with `[lint]` and `[lint.per-file-ignores]`.  
**Decision**: Merge the full ruff config from `ruff_toml.jinja2` into `pyproject_toml.jinja2` under `[tool.ruff]` + `[tool.ruff.lint]` + `[tool.ruff.lint.per-file-ignores]`. Delete `ruff_toml.jinja2`. Remove the `.ruff.toml` `_add` call from `generate_project.py`.
