# Implementation Plan: CLI Factory + Builder Architecture Refactor

**Branch**: `015-factory-builder-refactor` | **Date**: 2026-04-14 | **Spec**: [spec.md](./spec.md)  
**Input**: Feature specification from `specs/015-factory-builder-refactor/spec.md`

---

## Summary

Refactor the six command modules that contain type-specific if/elif dispatch
(`generate_entry_point`, `generate_driven_adapter`, `generate_model`,
`generate_use_case`, `generate_helper`, `delete_module`) to use a
**Factory + Builder** pattern. Each module type becomes a single class implementing
a `ModuleFactory` protocol. A new `ModuleBuilder` class (in `core/`) wraps the
existing lower-level utilities and provides the only API that factory classes may
call. Commands become thin: parse args → look up factory in registry → build →
persist. All existing CLI behaviour, file output, and error messages are preserved.

## Phase 1: Foundational Infrastructure

**Goal**: Introduce `ModuleFactory` protocol and `ModuleBuilder` class. No command
files are modified yet. All gates must be green before Phase 2.

### Deliverables

1. **`ModuleFactory` Protocol** (`src/scaffold_ca_python/factory/__init__.py`)
   - `@runtime_checkable` Protocol with single method `build(self, builder: ModuleBuilder) -> None`
   - Fully type-annotated under mypy strict

2. **`ModuleBuilder` class** (`src/scaffold_ca_python/core/module_builder.py`)
   - Constructor: `(project_root, project_ctx, module_ctx=None, dry_run=False)`
   - Internal collaborators: `FileWriter`, `TemplateRenderer`, `inject_dependencies`/`dry_run_inject`
   - Public API: `add_file`, `delete_file`, `render`, `add_dependency`, `add_param`, `get_param`, `persist`
   - `persist()` returns `list[Path]`; in dry-run mode delegates to `FileWriter(dry_run=True)`,
     applies `dry_run_inject` for deps
   - `persist()` also handles pyproject scripts update (`update_project_scripts` /
     `dry_run_scripts_update`) via a separate `scripts_entry` param (opt-in, for restapi)

3. **Tests** (`tests/factory/test_module_builder.py`)
   - Test `add_file` accumulates operations
   - Test `add_dependency` accumulates packages
   - Test `persist(dry_run=True)` returns paths, writes nothing
   - Test `persist(dry_run=False)` calls `FileWriter.execute` and `inject_dependencies`
   - Test `render` delegates to `TemplateRenderer`
   - Full mypy, ruff gates green

### Gates

- All 487 existing tests still pass
- `tests/factory/test_module_builder.py` green
- mypy strict: 0 new errors
- ruff: 0 violations

## Key Design Rationale (summary)

| Decision | Choice | Why |
|---|---|---|
| Factory contract | `typing.Protocol` | Structural subtyping; no inheritance coupling; mypy strict friendly |
| Registry location | Module-level constant per command | Single source of truth; no global registry indirection |
| Factory location | `factory/` sub-package | Mirrors Java reference layout; clear grouping |
| Builder wraps utilities | Yes, does not replace | Preserves existing test coverage; minimal change set |
| Exclusivity guard | Stays in command module | Cross-type concern; cannot live in one factory |
| `gpipe` / `vs` scope | Out of scope | No type dispatch to migrate; would be over-engineering |

See [research.md](./research.md) for full decision rationale.
